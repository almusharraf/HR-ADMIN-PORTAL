This is just the asset dev shell

The HR admin portal itself is server-rendered PHP — there is no page to render here. This file only exists so npm run dev has something to serve while Vite hot-reloads admin.js / admin.css.

To see the actual portal, start the PHP backend in another terminal: 

cd backend
php -S localhost:8080 -t public router.php

...then open http://localhost:8080/ (not this :5173 page).

See the root README.md for full setup instructions.
